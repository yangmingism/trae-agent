# HTTP 服务器

此文件夹包含将 Trae agent 作为 HTTP 服务器托管的相关元素，使用 FastAPI 实现。此功能仍在构建中，**请勿**在生产环境中使用。

## HTTP 服务器的预期功能

1. 服务器应该能够执行无状态操作。
2. 服务器应该能够处理并发请求。
3. 服务器应该始终以 JSON 格式响应，即使是流式响应。

## 额外预期功能

1. 服务器应该能够基于特定的 JSON 文件重现或重复操作。例如，给定一个轨迹，它可以重现特定步骤并遵循由另一个模型生成的新步骤。
2. 为确保请求的动态性，服务器应该支持基于请求 JSON 文件的不同模型、不同请求和不同输出格式。

## 开发路线图

1. 要构建一个功能齐全的 HTTP Trae agent，我们需要逐步将 `trae_agent` 拆分为更多基于组件的模块，并添加更多功能使其更加动态。一个具体任务是研究 `run` 函数是否可以接受一个名为 `model` 的额外参数。
2. 除了 `run` 函数外，其他函数也应该不仅可以通过 CLI 调用，还可以通过 HTTP 服务器调用，以满足第二个要求。
3. 为了处理并发请求，还需要确保 HTTP 服务器是无状态的——至少在处理不同文件夹中运行的 `run` 函数时是如此。
